# Changelog

## 1.0.0 — 2026-11-17

Primeira versão pública do Routine.

- Treinos personalizáveis de calistenia, com séries, repetições, cronômetros e descansos.
- Diário alimentar com rascunhos e reutilização de refeições.
- Histórico, ciclos, evolução e relatórios por período.
- Acesso pelo navegador do celular via QR Code na rede local.
- Backups, restauração e instalador próprio para Windows x64.

As próximas versões registrarão aqui as mudanças feitas a partir da 1.0.0.
