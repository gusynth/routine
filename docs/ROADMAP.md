# Roadmap

Prioridades e acompanhamento da primeira edição pública. Sem datas prometidas.

- [x] Concluir o instalador e o desinstalador Windows com a identidade visual do Routine.
- [ ] Validar instalação, atualização, remoção e preservação de dados em Windows descartável.
- [ ] Conferir o ciclo completo de abertura, uso somente no celular e encerramento do serviço.
- [ ] Ampliar a validação em celulares físicos, especialmente áudio com música e retomada.
- [ ] Revisar acesso e pareamento na rede local antes de ampliar os cenários de compartilhamento.
- [x] Finalizar documentação, capturas com dados fictícios e instruções da primeira release.

Já existem treinos personalizáveis, diário com rascunhos, cronômetros, relatórios, backups e acesso pelo celular. Consulte o README e o histórico de mudanças para conhecer o comportamento disponível.
